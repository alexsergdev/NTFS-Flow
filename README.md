# NTFS Flow for macOS

**NTFS Flow** — професійний нативний застосунок для macOS, створений для повноцінної роботи з NTFS-накопичувачами, зовнішніми SSD, USB-флешками та картами пам'яті. Інтерфейс розроблено на базі дизайн-системи **Velio HUD**.

## ✨ Основні можливості

* **Повноцінний запис на NTFS**: читання, редагування, збереження та створення файлів на будь-яких NTFS-дисках без обмежень.
* **Вбудований провідник накопичувачів**: швидкий перегляд, відкриття файлів, створення папок, перейменування, видалення та drag-and-drop прямо у додатку.
* **Smart-діагностика здоров'я**: 6-етапний аналіз стану диска, файлової системи, наявності помилок і затримок шини з розрахунком індексу здоров'я (Health Score).
* **Тестування продуктивності**: вимірювання швидкості читання/запису (Benchmark) та перевірка справжньої місткості флешок (Fake USB Test).
* **Верифіковане копіювання**: черга передачі файлів із контролем цілісності кожного байта за криптографічним хешем SHA-256.
* **Робота в системному рядку меню (Menu Bar)**: опційний фоновий режим для миттєвого автоперемонтування підключених дисків.
* **Звіти у форматі PDF**: детальний експорт результатів тестів і діагностики.

## 💻 Системні вимоги

* **Операційна система**: macOS 13.0 (Ventura), macOS 14.0 (Sonoma), macOS 15.0 (Sequoia) та новіші.
* **Сумісність процесорів**: 
  * Apple Silicon (M1, M2, M3, M4 — всі серії: Base, Pro, Max, Ultra).
  * Комп'ютери Apple на базі Intel (x86_64).
